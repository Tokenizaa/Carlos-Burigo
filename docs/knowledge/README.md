# Arquétipo Inicial da Base de Conhecimento — Inteligência Eleitoral

## Objetivo

Este diretório inicia o acervo metodológico que futuramente alimentará o RAG da Inteligência Eleitoral.

Regra: primeiro coletamos e classificamos fontes confiáveis; depois sintetizamos métodos em conhecimento operacional; somente depois indexamos para RAG.

## Critério de seleção

Priorizar:
- fontes acadêmicas e institucionais;
- métodos publicados e reproduzíveis;
- definições operacionais;
- fórmulas e pressupostos explícitos;
- limitações documentadas;
- fontes primárias ou referências acadêmicas reconhecidas.

Evitar:
- blogs opinativos como fonte metodológica;
- conteúdo de campanha como fundamento científico;
- textos sem método verificável;
- transformar opinião política em regra analítica.

O RAG não deve receber indiscriminadamente todo o conteúdo coletado. A base precisa ser curada e estruturada.

## Primeira coleção

A primeira coleção cobre competitividade eleitoral, previsão/modelagem, comportamento eleitoral, qualidade de dados eleitorais, análise territorial e geografia estatística.

Esta coleção é uma fundação, não uma lista definitiva.
